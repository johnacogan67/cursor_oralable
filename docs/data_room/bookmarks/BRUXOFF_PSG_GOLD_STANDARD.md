**One-liner:** In this study, lab **PSG (expert-scored)** is the SB/OSA diagnostic gold standard. **Bruxoff®** (masseter sEMG + EKG) counts more SB than PSG and is only moderately reliable in **no/mild OSA** — not in **moderate/severe OSA**. Oralable uses a **different modality** (temple optical). No Bruxoff/PSG concordance data yet.

---

## 1. Citation

Cid-Verdejo R, Domínguez Gordillo AA, Sánchez-Romero EA, Ardizone García I, Martínez Orozco FJ. Diagnostic Accuracy of a Portable Electromyography and Electrocardiography Device to Measure Sleep Bruxism in a Sleep Apnea Population: A Comparative Study. *Clocks & Sleep*. 2023;5(4):717–733. doi:[10.3390/clockssleep5040047](https://doi.org/10.3390/clockssleep5040047)

## 2. What they compared

| Tool | Role |
|------|------|
| **Lab PSG — manual expert** | **Gold standard** for SB (+ OSA staging) |
| **Bruxoff® — automatic** | Portable bilateral **masseter sEMG + EKG (HR)** |
| **Bruxoff® — manual** | Same hardware, human rescored |

- Design: PSG and Bruxoff recorded together; **n = 22** (suspected OSA); AASM OSA severity segments.  
- The paper notes EKG/HR vs EMG-only portables as a product difference.

---

## 3. Key results (bookmark numbers)

| Method | Mean SB episodes / night (approx.) |
|--------|-------------------------------------|
| PSG | **8.4** |
| Bruxoff manual | **14.6** |
| Bruxoff automatic | **22.7** |

| OSA stratum | ICC (SB episode counts across tools) | Interpretation |
|-------------|--------------------------------------|----------------|
| Non-OSA | ~**0.61** | Moderate |
| Mild OSA | ~**0.53** | Moderate |
| Moderate OSA | ~**0.24** | Poor |
| Severe OSA | ~**0.23** | Poor |

- Automatic Bruxoff runs about **+14** episodes above PSG (Bland–Altman class finding in the paper).  
- Authors: Bruxoff vs PSG is acceptable **only in non-OSA or mild OSA**. In **moderate/severe OSA**, apnea-related hypermotor activity can **confuse** portable EMG SB calls.

## 4. Where Bruxoff sits as a product

| Aspect | Status |
|--------|--------|
| Class | Ambulatory **masseter sEMG + EKG** SB screener |
| Landscape peer | Same family as BiteStrip / GrindCare / other EMG tools in Li 2025 ambulatory SB review |
| Strength | Portable overnight; some PSG comparison literature; HR channel for scoring support |
| Weakness (this paper) | Overestimates vs PSG; **weak when OSA is moderate–severe** — the comorbid group Pedro cares about |

## 5. Where Oralable is relative to this gold standard

| | Bruxoff | Oralable (31 Jul / 2 Aug 2026 truth) |

| Modality | Masseter **sEMG + EKG** | Temple **PPG / IR-DC OMG + ACC** (+ SpO₂ path) |

| vs PSG gold standard | Partial / conditional (worse with OSA) | **Not started** for SB events |

### Recommended ladder (do not skip)

1. **Paper A feasibility (now)** — Oralable usable; SpO₂ and ref pulse-ox; Pedro 1–2 h oxygen check as a **subset**; not “beats Bruxoff on SB.”  
2. **Adjacent gold standard (research)** — **Anterior temporalis sEMG** at the same time as IR-DC / Protocol A labels. Founder path: **ANR M40** Mac dual-BLE ([ANR_M40_CONCORDANCE.md](../clinical/ANR_M40_CONCORDANCE.md)); optional Bruxoff-class masseter later. Expect ~**1–5 s** hemodynamic lag.  
3. **Diagnostic gold standard** — **PSG (± AV)** for RMMA / SB — same bar used against Bruxoff; full Paper C / Stage B.

**ANR vs Bruxoff (do not conflate)**

| | Bruxoff | ANR M40 (research) |
