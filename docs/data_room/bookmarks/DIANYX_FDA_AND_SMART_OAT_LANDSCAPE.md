## 2. Snapshot judgment (31 Jul 2026)

| Player | Public FDA smart status | Competes with Dianyx as… |
|--------|-------------------------|--------------------------|
| **Dianyx t.e.s.a.** | No clearance found; 510(k) pre-sub underway; AASM “in development” | Sensor / RPM / OEM layer |
| **SomnoMed Rest Assure** | Compliance monitoring cleared (K233497); AHI/efficacy **not** cleared — trial path | Built-in compliance (+ future efficacy) inside own MAD |
| **ProSomnus RPMO₂** | Class II cleared Apr 2026 (SpO₂ + pulse in appliance) | Cleared physiologic monitoring inside own MAD |

**Likelihood (qualitative):** A narrow 510(k) for adherence/vitals is **plausible but not imminent**. Broad AHI / AI efficacy claims are **harder** (SomnoMed already hit that wall on Rest Assure). Dianyx is **not** a near-term peer to SomnoMed/ProSomnus as MAD platforms.

**Oralable implication:** Phase 2 complementarity only if Dianyx clears and stays appliance-agnostic — intraoral t.e.s.a. beside extraoral Oralable. Do not frame Oralable as racing their FDA file.
