# Euro display rate — MAM public site

**As at:** 21 Oct 2026  
**Tone:** the rate used to print a dollar beside a euro on the public MAM site. Not a price. Not a bill.  
**Site:** [mam67.netlify.app](https://mam67.netlify.app/) · source repo `johnacogan67/mam-website`

**One-liner:** On 20 October 2026 the European Central Bank set one euro at 1.1215 US dollars. The site rounds each dollar figure to the nearest dollar. Euro stays the price.

The jaw-pressure question uses 1.7 MPa, with 250 lb/sq.in. beside it. 250 pounds per square inch is 1.72 MPa. The page rounds that to 1.7.

## What this does not say

The dollar is not the price, and it is not money already billed. Do not copy these dollars into the governance notes, the go-to-market page, or a pitch as if they were quoted prices. The rate moves. Read the ECB PDF again before the next public update.
