# Bookmark — Happy Ring (Happy Health)

**As at:** 30 Aug 2026 · Pack **1.1.68** (bookmark content unchanged)  
**Context:** Finger **smart-ring** HSAT / physiologic monitor. Oura-like jewelry form. Not a bruxism or temple device.  
**Related:** [ACUPEBBLE_VS_ORALABLE_ANR.md](./ACUPEBBLE_VS_ORALABLE_ANR.md) · [ORALABLE_RESEARCH_KIT.md](../clinical/ORALABLE_RESEARCH_KIT.md) · landscape [ORALABLE_MARKET_LANDSCAPE.md](./ORALABLE_MARKET_LANDSCAPE.md) §7.9

**One-liner:** Happy Ring is an **Oura-class ceramic finger ring** with FDA Class II clearances for **physiologic monitoring** and a **home sleep-test SaMD** that reports **hAHI**. Same overnight-sleep shelf as AcuPebble / Wellue. Different site and job from Oralable (finger HSAT vs temple jaw-load). Complementary nest, not a substitute.

## 2. Snapshot vs Oralable

| | **Happy Ring** | **Oralable** Gen1 |
|--|----------------|-------------------|
| **Form** | Finger ring (ceramic jewelry; ~Oura size) | Temple **clip** |
| **Site** | Finger (high perfusion) | Extraoral **anterior temporalis** |
| **Primary job** | Home **OSA** aid (hAHI) + 24/7 vitals | Temple **HR/SpO₂** + later IR-DC jaw-load |
| **Signals** | PPG + ACC (+ EDA / electrodes / temp per company) | Reflective R/G/IR PPG + ACC + temp |
| **Headline output** | **hAHI**, TST (K242224); SpO₂ / HR (K240236) | HR, SpO₂, (later) TFI / hypnogram; SASHB = SpO₂&lt;90 AUC — **not** Azarbarzin HB |
| **Regulatory** | Class II **cleared** (MWI + MNR) · Rx / HCP-directed sleep test | Stage A **wellness / research** — not HSAT-cleared |
| **SB / bruxism** | **Not** its claim | Optical jaw-load path (Phase 1+) |
| **Fits Pedro** | Another **AHI-class** finger HSAT (like AcuPebble / Belun) | **Arm P** companion **with any MAD** — nest, do not clone AHI |

K242224 IFU (FDA, not marketing): SaMD that uses wearable data **to aid in evaluating sleep-related breathing disorders** in adults **22+**, clinical or home, **under a trained healthcare provider**. Clinician interprets hAHI. Company copy (“diagnoses OSA”) is stronger than the IFU — do not repeat that in Oralable materials.

## 3. Claim discipline

| Do | Do not |
|----|--------|
| Call it an **Oura-like finger ring** with **cleared HSAT SaMD** (hAHI) | Call Oralable a sleep-apnea ring or HSAT |
| Nest beside AcuPebble as **AHI-class** context for Arm P | Say Oralable SpO₂ / SASHB **=** hAHI or AcuPebble AHI |
| Cite K240236 + K242224 | Cite the **97% vs PSG** figure as Oralable-verified |
| Note Belun / NightOwl as the same **MNR ring/HSAT** class | Treat Happy Ring as a bruxism or temporalis peer |
| Keep Pedro’s **AcuPebble** as the Beacon AHI tool he already uses | Imply Happy Health partnership or that Pedro should switch |
