Slide 3 · Problem

Wrong site, episodic tools

Sleep bruxism damages teeth, drives jaw pain, and correlates with overnight oxygen burden.

  • Rings / watches — general wellness at finger/wrist; wrong site for jaw load
  • Clinic EMG — accurate but episodic, expensive, not overnight consumer
  • Gap — no continuous at-home optical + motion record of jaw hemodynamics

Condition-specific problem — not “another sleep tracker.”
